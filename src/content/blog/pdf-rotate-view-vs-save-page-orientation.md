PDF 문서를 90도 돌려서 읽기 편하게 만든 뒤 저장했는데, 다시 열면 원래 방향으로 돌아가는 일이 있습니다. 이때 파일이 고장 난 것은 아닐 수 있습니다. **화면에서만 방향을 바꾸는 '보기 회전'을 했는지, PDF 파일 자체의 페이지 방향을 바꾸는 '페이지 회전'을 했는지**가 다르기 때문입니다.

보고서 한 페이지가 옆으로 누워 있거나 스캔 자료 일부가 거꾸로 들어왔을 때, 수정해서 동료에게 보내려면 **실제 페이지 회전 후 새 파일을 저장하고 다시 열어 검수**해야 합니다. 단순히 내 화면에서 바로 보이게 만드는 것과 수신자에게 올바른 파일을 전달하는 것은 다른 작업입니다.

## 보기 회전은 읽기 위한 설정에 가깝다

어떤 PDF 앱은 화면을 90도 돌리는 기능을 제공합니다. 화면은 즉시 정상적으로 보이지만, 원본 페이지의 방향 정보가 바뀌었다는 의미는 아닙니다. 앱을 닫았다가 다시 열면 누워 있던 페이지가 그대로 나타날 수 있습니다.

[Adobe의 한국어 공식 PDF 보기 안내](https://helpx.adobe.com/kr/acrobat/using/adjusting-pdf-views.html)도 **'페이지 보기 회전'은 실제 페이지 방향이 아닌 보기만 바꾸며 저장할 수 없다**고 구분합니다.

| 필요한 결과 | 적용해야 할 작업 | 검수 방법 |
| --- | --- | --- |
| 내 화면에서 잠깐 읽기 쉽게 보기 | 보기 회전 | 닫았다 다시 열 때 원래대로여도 이상이 아님 |
| 파일을 열 때마다 바른 방향으로 유지 | 페이지 구성에서 실제 페이지 회전 | 저장하고 다시 열어 같은 방향인지 확인 |
| 인쇄본만 종이 방향에 맞추기 | 인쇄 설정의 용지 방향·자동 회전 확인 | 출력 미리보기와 실제 출력 확인 |
| 특정 페이지만 방향 고치기 | 페이지 범위를 지정한 회전 | 수정한 페이지와 손대지 않은 페이지를 대조 |

특히 **인쇄 설정에서 가로로 출력되게 고친 것**과 **PDF 내부 페이지를 고친 것**도 다릅니다. 인쇄물이 정상이라고 해서 파일 자체도 정상으로 저장됐다고 판단하면 재작업이 생깁니다.

## Acrobat에서 페이지 방향을 파일에 남기는 순서

Adobe의 [PDF 페이지 회전 공식 안내](https://helpx.adobe.com/kr/acrobat/desktop/edit-documents/organize-pages/rotate-pages.html)에 따르면 데스크톱 Acrobat에서는 **모든 도구 → 페이지 구성**에서 회전할 페이지를 선택하고 왼쪽·오른쪽 회전을 적용한 뒤 저장합니다. 제품 버전과 화면 구성에 따라 메뉴 위치가 다를 수 있으며, 사용하는 라이선스나 앱에서 편집 기능을 지원하지 않으면 해당 메뉴가 제한될 수 있습니다.

실제 작업은 다음처럼 구분해서 진행하세요.

1. **원본을 복제합니다.** 예를 들어 `고객제출_원본.pdf`를 그대로 두고 `고객제출_방향수정_검토본.pdf`을 작업 파일로 만듭니다. 회전 도중 다른 페이지의 순서까지 바뀌었을 때 되돌릴 기준본이 필요합니다.
2. **문제가 있는 페이지 번호를 적습니다.** 전체 문서가 잘못된 것인지, 4쪽만 옆으로 누웠는지 확인합니다. 페이지 번호는 PDF 뷰어의 페이지 번호와 문서 본문에 인쇄된 번호가 다를 수 있으므로 뷰어 쪽 숫자를 기준으로 기록합니다.
3. **보기 회전이 아닌 페이지 구성 도구를 엽니다.** 회전 대상 페이지 또는 범위를 선택합니다. 모든 페이지를 일괄 회전하면 정상인 표지와 다른 쪽까지 돌아갈 수 있습니다.
4. **왼쪽 또는 오른쪽으로 90도 회전합니다.** 거꾸로 된 페이지는 필요한 방향을 다시 확인합니다. 한 번에 180도 회전해야 한다면 도구가 지원하는 방법에 따라 조정하세요.
5. **새 이름으로 저장한 뒤 닫고 다시 엽니다.** 보기 회전 설정이 초기화된 상태에서도 해당 페이지만 바른 방향이면 파일 수정이 반영된 것입니다.

페이지 구성을 지원하지 않는 PDF 뷰어라면 보기 회전으로 해결하려 하지 말고, **사용 권한이 있는 정식 PDF 편집 도구**에서 원본을 다시 열어 수정해야 합니다. 회사가 승인하지 않은 온라인 변환 사이트에 내부 문서를 올리는 것은 피하세요.

## 스캔 PDF와 문서 PDF의 확인 지점은 다르다

스캔 자료는 이미지 자체가 한쪽으로 돌아간 상태일 수 있습니다. 페이지 방향만 바꾸면 읽기는 편해지지만, **기울어진 스캔의 수평 보정**까지 자동으로 해결되지는 않습니다. 글자가 대각선으로 기울어진 것과 페이지가 90도 회전한 문제는 다른 종류입니다.

또한 OCR(이미지에서 문자를 인식한 텍스트 층)이 포함된 PDF는 화면상 회전 후 검색·복사 결과까지 이상 없는지 확인할 필요가 있습니다. 방향이 고쳐졌다고 인식된 문자 내용이 자동으로 정정되는 것은 아닙니다.

문서 PDF라면 표나 가로 페이지를 포함할 수 있습니다. 가로 페이지가 모두 오류는 아닙니다. 예를 들어 보고서 1~3쪽은 세로이고 4쪽의 넓은 표만 가로인 경우, **4쪽이 읽는 방향에 맞게 보인다면 그 페이지를 억지로 세로로 돌릴 필요가 없습니다.** 페이지마다 의도된 레이아웃을 존중해야 합니다.

## 저장했는데도 다시 돌아간다면 세 가지를 의심

**편집 대상이 원본이 아니었던 경우.** 메일 첨부파일을 미리보기에서 회전했는데 실제로는 로컬 원본을 수정하지 않았을 수 있습니다. 저장된 파일의 경로와 파일명을 확인하세요. 공유 폴더에 복사본이 여러 개 있다면 수정한 파일이 어느 것인지 먼저 좁혀야 합니다.

**보기 회전만 누른 경우.** 문서를 닫고 다시 열어 확인하는 테스트가 가장 빠릅니다. 재열기 후 방향이 원래대로라면 실제 페이지 편집이 반영되지 않았을 가능성이 큽니다.

**권한이나 편집 기능이 제한된 경우.** 읽기 전용 파일, 보안 설정이 걸린 문서, 편집 기능이 없는 뷰어에서는 회전한 상태를 저장할 수 없을 수 있습니다. 원본 파일의 편집 권한과 사용 중인 프로그램 기능을 확인하고, 권한 우회나 무단 변환 대신 문서 소유자에게 수정본을 요청하세요.

## 외부 전달본은 회전만 확인하면 부족하다

방향을 수정한 후에는 **페이지 수, 페이지 순서, 표의 가로 잘림, 글자 검색 가능 여부**까지 함께 확인하세요. 보기 화면은 정상인데 PDF로 다시 출력하는 과정에서 여백이나 축소 비율이 바뀌는 경우가 있습니다. 특히 보고서에 큰 표가 들어 있다면 [엑셀 PDF 변환 시 열이 잘리는 문제](/blog/excel-pdf-print-cuts-off-columns-fix/)도 서로 다른 검사 항목입니다.

검수할 때는 문서를 처음 페이지부터 끝까지 빠르게 넘기면서 가로·세로 혼합 페이지의 방향을 확인합니다. 이어서 파일을 닫고 다시 열고, 보내려는 폴더의 최종 파일을 한 번 더 열어 봅니다. 여러 PDF를 병합해 전달하는 상황이라면 [PDF 합치기 전 페이지 순서 검수](/blog/pdf-merge-page-order-version-check/)도 필요합니다.

수신자가 열었을 때의 방향을 보장하려면 **내가 보고 있던 창의 방향이 아니라, 재열기한 최종 파일의 페이지 방향**을 확인해야 합니다. 이 검수 하나로 '수정했는데 왜 다시 돌아갔나요?'라는 재작업을 상당 부분 예방할 수 있습니다.
