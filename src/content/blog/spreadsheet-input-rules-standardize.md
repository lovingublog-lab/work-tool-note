스프레드시트를 여러 사람이 함께 쓰면 데이터가 틀리는 것보다 **같은 뜻을 서로 다른 방식으로 입력하는 문제**가 더 자주 생깁니다. 완료, 완료됨, 처리완료가 섞이고 날짜 형식이 제각각이면 나중에 필터와 집계를 할 때 매번 다시 정리해야 합니다.

## 열마다 허용할 값을 먼저 정한다

긴 매뉴얼보다 열 이름, 셀 메모, 예시 행처럼 실제 입력 화면에서 바로 볼 수 있는 규칙이 효과적입니다. 상태 열은 대기·진행중·완료·보류처럼 제한하고, 담당자 열도 한 가지 표기 방식으로 통일하세요.

## 날짜는 한 형식으로 통일한다

10/2, 2026.10.02, 2026-10-02처럼 여러 형태가 섞이면 정렬과 집계가 불안정해질 수 있습니다. 한 열에서는 하나의 날짜 형식만 사용하고 실제 날짜 값으로 인식되는지도 확인합니다.

## 상태값은 자유입력보다 선택값이 낫다

종류가 많지 않은 값은 자유롭게 타이핑하게 두면 오타와 표현 차이가 늘어납니다. 실제 업무 판단에 필요한 상태만 남기고 선택형 입력을 쓰면 관리가 쉬워집니다.

## 담당자 표기도 하나로 맞춘다

같은 사람을 이름, 별칭, 영문명으로 섞어 쓰면 필터에서 다른 사람처럼 보일 수 있습니다. 동명이인이 있다면 조직에서 허용하는 식별 기준을 추가하되 불필요한 개인정보는 넣지 않습니다.

## 빈칸의 의미를 구분한다

빈칸이 미입력인지 해당 없음인지 구분되지 않으면 나중에 상태를 판단하기 어렵습니다. 필요하다면 미입력, 해당없음처럼 의미가 다른 값을 따로 두고 입력 필수 열과 선택 열을 구분하세요.

## 숫자와 단위를 섞지 않는다

수량 열에 10개, 5박스처럼 단위를 붙이면 합계와 정렬이 어려워질 수 있습니다. 계산이 필요한 열은 숫자만 입력하고 단위는 열 제목이나 별도 열에서 설명하는 방식이 안정적입니다.

이미 뒤섞인 데이터를 정리해야 한다면 [스프레드시트 원본 데이터를 정리할 때 먼저 맞춰야 할 기준](/blog/spreadsheet-raw-data-cleanup/)을 참고할 수 있습니다. 반복 업무라면 매번 사후 정리하기보다 입력 단계에서 오류를 막는 편이 효율적입니다.

좋은 입력 규칙은 설명이 짧고 입력자가 바로 이해할 수 있으며 필터와 집계가 예상대로 동작합니다. **날짜·상태·담당자·빈칸처럼 반복해서 문제가 생기는 값부터 표준화하세요.**
